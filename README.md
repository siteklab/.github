# siteklab/.github

Organization-wide files for the [Speech and Hearing Pathways Lab](https://siteklab.github.io) on GitHub.

- [`profile/README.md`](profile/README.md): the profile shown on [github.com/siteklab](https://github.com/siteklab)
- [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md): defaults for every lab
  repository that doesn't have its own

GitHub only uses these defaults while this repository is public.
